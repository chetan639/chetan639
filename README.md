### 🧑‍💻 About me

I'm a backend engineer in Bengaluru, working on payments infrastructure at **Razorpay**. I like reading code, figuring out how systems behave under load, and automating anything I end up doing twice.

- ⚙️ I own a core banking accounts service handling **800+ TPS** on Razorpay's payout stack
- 🔄 I led a **zero-downtime CRM migration** across 3 teams using the outbox pattern, Kafka and async workers
- 🤖 I build **AI agents for developers**: one ships SDK releases and updates the repos that depend on them, another auto-fixes flaky CI on a large monolith (95%+ of failures resolved without a human)
- 🌊 I built a **CDC pipeline** that streams DB changes through Kafka into a data lake for near-real-time analytics
- 🎓 B.Tech CSE, IIIT Sri City · previously at SurveySparrow and AutomationEdge
- ⚽ Off the keyboard I'm pretty decent at football
